# Link Stash: Library App Spec

Part 2 of 2. Part 1, the pipeline that fills the library, is in [link-stash-spec.md](link-stash-spec.md). This app reads and edits what part 1 writes, through the same Python core. Progress tracking across all milestones is in [progress-tracker.md](progress-tracker.md).

## Overview

A local, library-first web app for the stash. You browse a thumbnail grid of everything saved, open a card to see its properties, notes and connections, watch the saved reels, and work the stash-specific lists (pending, rejected, inventory). Triage stays in Claude Code and Antigravity; the app never judges, extracts or calls an LLM.

**Goals (v1)**

- Browse, search and filter every card, source and inventory entry.
- Edit what is yours on a card: category, kind, tags and the Notes section.
- See how things connect: backlinks, local graph, global graph.
- Stash views: Feed, Sources with a video player, Pending, Rejected, Inventory.
- Reflect changes made from the CLI within a second, without a refresh.

**Non-goals (v1)**

- No triage, link pasting for extraction, or LLM calls.
- No access from other devices. The server binds to `127.0.0.1` only. LAN access with a token is a v2 item.
- No in-app tabs. Every view has a URL; Ctrl+click opens it in a browser tab.
- No full-body markdown editing in the app. Agent-written sections are read-only here; edit the file by hand if needed.
- No charts or stats page.
- No plugins, canvas, daily notes or sync. The library folder is plain files; back it up however you like.
- No accounts or auth (single local user).

## Locked decisions

| Area | Decision | Why |
| --- | --- | --- |
| Approach | Own local web app, not an Obsidian plugin | Full control of design and stash-specific views; no closed-source dependency |
| UI model | Library-first: sidebar + thumbnail grid, card page with a properties column. No in-app tabs | Reels are visual; browser tabs already do tabs; removes tab/router sync |
| Backend | `stash serve` (FastAPI in the core package) | Same services and lock as the CLI; one writer |
| Frontend | Vite + React + TypeScript strict, TanStack Router + TanStack Query | Local single-page app with FastAPI as its backend; Next.js server features would go unused |
| Process | One process, one port: `stash serve` serves the API and the built frontend | Nothing else to start |
| API contract | REST, OpenAPI generated by FastAPI, TS types by `openapi-typescript`, calls via `openapi-fetch` | One contract, no hand-copied types |
| Live updates | Server-Sent Events from the file watcher | One-way is all that is needed |
| Editing | Card body rendered read-only; properties form + CodeMirror 6 editor for the Notes section only | Agents write the body; you own Notes and properties. No live-preview extension to build |
| Graph | sigma.js + graphology, ForceAtlas2 in a web worker; local + global; built last (B5) | WebGL, smooth with thousands of nodes; least critical view |
| Search | Server-side SQLite FTS5; one Ctrl+K palette built on cmdk (shadcn `Command`) | Index already exists in the core; one palette covers title and full text |
| UI kit | [shadcn/ui](https://ui.shadcn.com) on Radix + Tailwind, Vite template, styled only through tokens in one global file | Your CLAUDE.md standard; every third-party registry targets Radix |
| Icons | [Hugeicons](https://hugeicons.com/icons/stroke-rounded) stroke-rounded (free set), set as shadcn `iconLibrary: "hugeicons"` | One rounded set; shadcn installs components with it |
| Icon morphs | [morphicons](https://www.morphicons.com) (~6 KB) fed Hugeicons path data | Menu ↔ close, play ↔ pause, filter open ↔ close |
| Brand logos | [theSVG](https://thesvg.org) SVGs copied into `src/assets/brands/` | Instagram, GitHub, Hugging Face, Notion, Ollama, LM Studio, Claude, Gemini; no runtime dependency |
| Motion | CSS transitions by default, recipes copied from [transitions.dev](https://transitions.dev) (free library). [Motion](https://motion.dev) (`LazyMotion` + `m`) only for grid reorder and list enter/exit. Tile → card shared transition uses the native View Transitions API | CSS where it can; Motion only where CSS cannot. The card route is code-split, so the tile unmounts before the card mounts and Motion `layoutId` has nothing to animate from |
| Small deps | `zod` (URL search-param schemas), `react-markdown` (read-only body), `@fontsource-variable/geist` + `geist-mono` (offline fonts), `culori` (dev only, contrast test); core: `tomlkit` (writes `config.toml` category colors without losing comments) | Each replaces code we would otherwise write |
| Scroll | [Lenis](https://lenis.dev) on the main content scroll container | Smooth scrolling; respects reduced motion by default |
| Theme | Light and dark from day one, follows the system, manual toggle | Graph and video views read better dark; tokens make it cheap |
| Visual direction | Quiet neutral: zinc neutrals, one indigo primary, Geist Sans, thin borders, soft shadows, radius `md`/`lg` | Thumbnails carry the color; the chrome stays out of the way |
| Frontmatter editing | Typed form, never raw YAML | Validated by the same Pydantic models as the CLI |
| Conflicts | Content hash on every write; mismatch returns 409 | Never silently overwrite a CLI or hand edit |
| Delete | Moves the card to rejected with a reason | It will not be suggested again |

**Considered and not used:** remocn (its icons and components depend on Remotion and target video, not app UI; candidate for a Link Stash demo video later), assistant-ui (no chat in the app), kokonutui, tailark blocks, vengeance UI and collectui (landing-page sections and footers; the app has neither), reactbits (effects clash with the quiet direction), keylineicons (second icon set; not a shadcn `iconLibrary`), bklit-ui and amicro mono-charts (no charts in v1). refero.design is a reference for B0 only.

## Features

**Grid and tiles**

- The Feed, category pages and search results share one virtualized grid component.
- A tile shows `thumb.jpg` from the card's first source, the title, and the category as a small pill with its category color.
- **Generated tile** when a card has no thumbnail (a pasted GitHub/HF link, practice cards): a background tinted by the category token, the kind icon, then owner and name (or the practice's first words). No network fetch.
- Source platform shows as a small brand logo (theSVG) on the tile.
- When filters change, tiles reorder with a Motion layout animation; opening a tile uses a shared transition into the card page header.

**Card page**

- The body (**What it is**, **Why it fills a gap**, **Origin**) renders as read-only markdown. `[[slug]]` links resolve to card pages; unknown slugs render as unresolved.
- **Notes** is a small CodeMirror 6 editor (`@codemirror/lang-markdown`), with `[[slug]]` autocomplete from the index.
- Autosave runs 800 ms after the last keystroke and sends the hash the edit was based on. On 409 a banner offers "Reload from disk" or "Keep mine" (which re-sends with the new hash). Saving changes only the Notes section of the body.
- The `⋯` menu has **Reject**, which opens a dialog asking for a reason, then moves the card to rejected.

**Properties panel**

- Renders the card's frontmatter as a form: category (select; changing it moves the file through the core), kind (select), tags (chip input with autocomplete). Everything else (`key`, `title`, `url`, `sources`, `facts`, `features`, `added`) is read-only.
- `overlaps` shown as links to the other cards or inventory entries.
- Validation errors from the API (Pydantic) appear next to the field.

**Search and navigation**

- Ctrl+K: command palette. Typing searches titles, bodies, transcripts and captions (FTS5, highlighted snippets) and lists commands (go to Pending, toggle theme, rebuild index).
- Filters on grid and list views: kind, category, tag, creator, date range, has video. Filter state lives in the URL query so views are linkable.

**Backlinks and graph**

- Card page properties column: **Backlinks** (cards whose `[[slug]]` or `overlaps` point here), **Mentioned by** (sources), **Outgoing**.
- Local graph: 1 hop by default, 2 hops toggle, centered on the open card.
- Global graph at `/graph`: nodes are cards (colored by category), sources (thumbnail on hover) and creators; edges are `source`, `overlap` and `wikilink`. Filter by category and edge type. Click a node to open it.
- Layout runs ForceAtlas2 in a web worker so the main thread stays free.

**Stash views**

- **Feed.** The grid above. Sources that produced no saved card are not shown.
- **Source view.** HTML5 `<video>` playing the local `video.mp4` (served with HTTP range requests so seeking works), poster from `thumb.jpg`, play/pause icon morphs. The transcript and mentions show `MM:SS` stamps that seek the player. Lists the cards that came from this source and links to the original reel.
- **Pending.** Each item shows the instruction ("Comment `GUIDE` on <reel>") and a field to paste the link that arrived by DM. Resolving stores the link and marks the item ready; the next `/stash` run in a CLI triages it.
- **Rejected.** Key, date, reason. Un-reject removes the entry so the thing can be suggested again.
- **Inventory.** Grouped by tool (auto, with the tool's brand logo) and manual file. "Add" calls the same `have` service as `/stash-have`.

**Empty and error states**

- Empty Feed on first run: "Paste links into `/stash` in Claude Code or agy." Empty Pending and Rejected say so in one line.
- API errors show as a toast with the error `message`; a lost SSE connection shows a small "reconnecting" indicator in the sidebar.

**Live sync**

- The app opens one SSE connection to `/api/events`. Events: `card.changed`, `card.deleted`, `source.changed`, `state.changed` (pending/rejected/queue/inventory), `index.rebuilt`.
- Each event invalidates the matching TanStack Query keys. An open card with no unsaved Notes edits reloads silently; one with unsaved edits shows the 409-style banner.
- The connection reconnects with backoff and refetches on reconnect.

## API (served by `stash serve`)

All list endpoints take `cursor` and `limit` (default 50, max 200) and return `{items, next_cursor}`. Errors use the core's shape `{"error": {"code", "message", "details"}}`.

| Method and path | Purpose |
| --- | --- |
| `GET /api/cards` | List with filters: `category`, `kind`, `tag`, `creator`, `since`, `until`, `has_video` |
| `GET /api/cards/{slug}` | Frontmatter, body, hash |
| `PUT /api/cards/{slug}` | Save the Notes section and editable frontmatter with `base_hash`; moves the file if category changed; 409 on hash mismatch |
| `DELETE /api/cards/{slug}` | Reject with `reason` |
| `GET /api/cards/{slug}/links` | Backlinks, mentioned-by, outgoing |
| `GET /api/graph` | Global graph, or `center` + `depth` for a local graph; filter by category and edge type |
| `GET /api/search` | FTS5 search with snippets |
| `GET /api/sources`, `GET /api/sources/{id}` | Sources list and detail |
| `GET /api/sources/{id}/video`, `/thumb` | Media files, range requests supported |
| `GET /api/pending`, `POST /api/pending/{id}/resolve` | Pending list, resolve with a URL |
| `GET /api/rejects`, `DELETE /api/rejects/{key}` | Rejected log, un-reject |
| `GET /api/inventory`, `POST /api/inventory` | Inventory list, add an entry |
| `GET /api/meta` | Categories (with color token), tags, counts, core version |
| `GET /api/events` | SSE stream |
| `POST /api/reindex` | Rebuild the index (palette command "rebuild index") |

Routes are thin: validate, call a service, return. Every write goes through the core services and the lock.

## Frontend structure (`apps/web`)

```
apps/web/
  components.json         shadcn config: style, Radix base, iconLibrary "hugeicons", aliases
  src/
    styles/tokens.css     the one global token file: color (light + dark), category colors, type, space, radius, shadow, motion
    components/ui/        shadcn primitives, added once: Button, Dialog, Popover, Select, Tooltip, Sonner (toast), Command, Sheet (drawer), ChipInput, ...
    components/           app-wide pieces built once: Grid, Tile, GeneratedTile, BrandLogo, MorphIcon wrapper, TextMorph (torph), ThemeCord (feralui)
    assets/brands/        theSVG logos
    features/
      card/               rendered body, Notes editor (CodeMirror), wikilink completion
      properties/         frontmatter form
      graph/              sigma wrapper, layout worker
      search/             palette, filters
      sources/            player, transcript
      pending/ rejected/ inventory/ feed/
    routes/               TanStack Router file routes
    api/                  generated schema types + openapi-fetch client + query keys
    state/                React Context: sidebar, theme
    lib/                  SSE client, Lenis setup, small helpers
  vite.config.ts          dev proxy /api -> stash serve
```

- **Server state** is TanStack Query only. **Client state** (sidebar, theme) is React Context. No Redux or Zustand.
- **Routes are code-split.** The graph (sigma), the Notes editor (CodeMirror) and Motion load only when first used.
- **Lenis** wraps the main content scroll container only. The Notes editor, palette, dialogs, drawers and the graph carry `data-lenis-prevent`. TanStack Virtual reads the same container.
- **Dev:** `stash serve --dev` (API only) plus `pnpm dev` with Vite proxying `/api`. **Use:** `pnpm build` once, then `stash serve` serves `apps/web/dist`. If `dist` is missing, `stash serve` exits with a message telling you to build it.

## Design system

- One token file (`styles/tokens.css`) holds every color, type size, space step, radius (`sm`, `md`, `lg`, `full`), shadow, and motion duration/easing, with light and dark values on semantic names following shadcn (`--background`, `--foreground`, `--muted`, `--muted-foreground`, `--border`, `--primary`, `--destructive`) plus `--success`, `--warning` and `--cat-*`, so no shadcn primitive is edited. shadcn and Tailwind read them as CSS variables. No component contains a hex or px value.
- **Category colors:** one token per seed category (`--cat-models`, `--cat-skills-plugins`, ...), plus 8 extra tokens (`--cat-extra-1` to `--cat-extra-8`). A new category takes the next free extra token, stored in `config.toml` so it stays stable. Used by pills, generated tiles and graph nodes.
- **Direction:** quiet neutral. Zinc neutrals, one indigo primary, Geist Sans (Geist Mono for keys and timestamps), thin borders, soft shadows, rounded corners everywhere, generous whitespace.
- **Motion:** CSS transitions on `transform` and `opacity`, recipes from transitions.dev; Motion only for layout and presence; everything respects `prefers-reduced-motion` (Lenis, Motion, morphicons, torph and the theme cord all fall back to instant).
- **Small extras (B6):** torph morphs sidebar counts and the header title on view change; the theme toggle is a feralui pull-cord at the bottom of the sidebar, with a plain keyboard-accessible toggle button behind it.
- **Accessibility:** semantic HTML, full keyboard navigation (every action reachable without a mouse), visible focus rings, ARIA from Radix, WCAG AA contrast checked once in the token palette for both themes.
- The concrete palette values, type scale and space scale are set in milestone B0, before any screen is built.

## Build order

Starts after core milestone A7, when the card format, store and index exist.

1. **B0 Visual design pass.** Palette (light + dark), category colors, Geist type scale, space scale, radius, motion tokens, written into `tokens.css`; shadcn init (Radix, Hugeicons); static mock of the Feed grid and the card page in both themes, using refero.design for reference. *Done when* you approve the tokens and the mock.
2. **B1 Serve and API.** `stash serve`, every endpoint above, SSE from the watcher, OpenAPI → TS types. *Done when* API tests pass and a card saved from the CLI emits a `card.changed` event.
3. **B2 Shell, grid, search.** Sidebar and drawer, Lenis, the shared grid with tiles and generated tiles, Feed, category pages, Ctrl+K, filters, empty states. *Done when* every card is reachable by sidebar, palette and filters at both mobile and desktop widths.
4. **B3 Card page.** Rendered body, Notes editor with wikilinks and autosave, 409 banner, properties form, category move, reject dialog. *Done when* editing Notes in the app and the file in VS Code at the same time never loses an edit.
5. **B4 Stash views.** Sources with player and seekable transcript, Pending resolve, Rejected, Inventory add, brand logos. *Done when* resolving a pending in the app is picked up by the next `/stash` run.
6. **B5 Backlinks and graph.** Properties-column link panels, local graph, global graph. *Done when* a reel with three saved cards shows the expected source and creator links in both graphs.
7. **B6 Polish pass.** Motion layout animation, View Transitions tile → card, morphicons, torph, feralui theme cord; responsive check at 375, 768, 1280 px in both themes; keyboard-only walkthrough; contrast check; bundle size check. *Done when* all four checks pass.
